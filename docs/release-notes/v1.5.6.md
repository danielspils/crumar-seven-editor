- MIDI Channel Auto-detect: the app now reads whatever MIDI channel your Seven is set to and talks to it there. If you’d moved yours off channel 1, the app couldn’t hear it — that’s fixed. It checks when it connects, so if you change the channel on the Seven, reconnect.
- If you have other gear on the same MIDI port, the app no longer jumps patches with the external gear.
- Backups now show their progress on a picture of the Seven’s own 32 buttons, lighting up as each preset is saved.
